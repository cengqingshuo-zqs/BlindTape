# 双盲K线训练 BlindTape 技术方案

*2026-09-22*

## 项目定位与目标

- 定位：一款用于个人训练的"双盲K线复盘"工具——随机抽取标的与时间窗口、隐藏代码和日期，逼迫自己脱离"看得出是哪年哪只"的后见之明去做买卖决策。
- 目标一：练习纪律化执行（进场/加仓/离场），检验自己在没有基本面/新闻线索时的盘感。
- 目标二：与现有 v1.1 趋势系统做同窗口对比——复盘时同步展示系统在同一段行情上的信号点位，看清"人工判断 vs 系统规则"的差异出在哪一步。
- 目标三：每次训练的完整明细可导出，喂给AI做归因分析（而不仅仅是看一个总收益率）。
- 边界：这是个人训练工具，不追求覆盖全市场品种的实盘交易，也不做资金管理/下单功能。

## 功能模块清单

1. 数据层（后台任务）：拉取全市场ETF列表+历史日线存本地，按上市时长/成交额门槛过滤出可训练标的池，定期增量更新
2. 随机抽样引擎：随机选标的+随机起点+随机窗口长度，校验窗口内数据完整性
3. 盲测训练前端（手机端网页）：K线逐根推进、隐藏代码和日期、买/卖/加仓/清仓操作面板、记录每步操作
4. v1.1系统信号复刻模块：脱离JoinQuant的独立实现，在同一份本地数据上逐日计算系统信号点位（进场/加仓/离场）
5. 复盘/揭晓页：揭晓真实标的和日期，叠加"你的操作 vs 系统信号"两条曲线，展示收益、回撤、在场时间对比
6. 导出模块：将单次训练的完整明细打包为JSON/CSV
7. 后端服务：部署在本地台式机，通过Tailscale供手机远程访问

## 数据方案（akshare）

- 数据源：akshare，开源库，抓取东方财富/新浪等公开接口，免费、无需API key
- 拉取ETF历史日线：`ak.fund_etf_hist_em(symbol, period, start_date, end_date, adjust)`
- 拉取全市场ETF列表（建标的池用）：`ak.fund_etf_spot_em()`
- 可用性/稳定性提醒：
  - 偶发东财接口反爬报错，社区有补丁插件应对；低频批量拉取+本地缓存的场景踩到概率低
  - 版本需跟随社区更新（`pip install akshare --upgrade`）
  - 自行加请求间隔（0.5~1秒/只），避免被当成爬虫封IP
- 标的池过滤规则（草案）：上市满2年 + 近期日均成交额门槛 + 有效交易日数量门槛，剔除历史不够长的迷你ETF

## 系统信号复刻模块

- 目的：让复盘页能展示"如果按 v1.1 系统规则操作，本该在哪买、哪加、哪卖"，与本人手动操作对比
- 复刻规则（与 v1.1 一致）：
  - 进场：收盘价站上 MA20，且 MA20 较前一日向上
  - 加仓：自首仓成本上行 1.5×ATR14（进场日锁定）→ 加第二段；上行 3.0×ATR14 → 加第三段，只在浮盈时加
  - 离场：连续4个交易日收于MA20下方 → 全部清出
  - 仓位节奏：首仓5% → 第二段+3% → 第三段+2%，单标的上限10%（此处仅用于计算对比曲线，不涉及真实仓位）
- 验证方式：挑几个历史标的，用本模块算出的信号点位和 JoinQuant 里跑出的结果核对，确认复刻没有偏差
- 备注：仅用于复盘对比展示，不作为训练前端的交易建议提示（避免破坏盲测的意义）

## 训练数据导出结构

每次训练会话导出为单个 JSON（可选配套CSV），至少包含：

- 会话元信息：训练时长、窗口长度、（揭晓后）真实ETF代码和名称、真实起止日期
- 完整OHLCV：该窗口内每日开高低收成交量
- 操作明细：模拟日序号、动作类型（买/卖/加仓/清仓）、价格、仓位变化，按时间顺序排列
- 由操作计算出的权益曲线、最大回撤、总收益、在场天数占比
- 系统信号点位：v1.1系统在同一窗口下的进场/加仓/离场日期和价格，及其对应的权益曲线、回撤、收益
- 用途：导出后可直接喂给AI，对比"人工决策"与"系统信号"两条曲线的分歧点，定位是哪一步（进场慢/加仓犹豫/离场恋战等）拖累了表现

## 开发顺序

1. 数据层脚本——独立可测，先把ETF池和历史数据在本地攒起来
2. 核心训练引擎（先不做UI，命令行/Jupyter里跑通）——抽标的、抽窗口、逐根喂数据、记操作、算权益曲线、导出JSON，先把导出数据结构定下来
3. v1.1系统信号复刻——独立实现后用历史标的和JoinQuant结果核对，确保信号点位一致
4. 最小可用网页界面（手机端）——FastAPI后端 + 轻量K线图表库，跑通"随机抽样→逐根推进→操作→复盘→导出"全链路
5. 部署到本地台式机，接入Tailscale，手机端联调
6. 迭代打磨——历史训练记录管理、多种训练模式等

## 部署方案

- 服务器：本地台式机（无公网域名），作为长期后台运行的服务器
- 内网穿透：用 Tailscale（或同类 ZeroTier）组私有网络，手机装App后与家里机器直连，出门用流量也能访问；免费、部署快、不需要域名和HTTPS证书，也不把单人自用工具暴露在公网
- 不采用 ngrok / Cloudflare Tunnel 等临时公网链接方案：链接每次重启会变，不适合长期天天使用的场景
